# Homepage visual studies

Date: 2026-09-15. Status: Ink & Paper (Option 1) selected as the starting point.
Created with the built-in image-generation tool. These are images, not working
HTML prototypes. Responsive behavior, accessibility, and interactions are untested.

All three explore the same editorial brief: Danilo Poccia first, Notes Along the
Way beneath; a featured article, three recent stories, visible collections/books,
and a photographic feature. The existing portrait was supplied as the identity
reference. Story text, book covers, and photography are illustrative, not actual
published works or the author's photographs. Incidental generated slogans and
extra copy are not approved content. Requested canvas: 1440 × 1600 desktop.

## Generation brief

Each independent prompt used the same content and name hierarchy, an attached
portrait from `static/images/danilo_poccia_highres.jpg`, readable editorial UI,
limited typography, purposeful spacing, and no SaaS sales controls or dashboard
metrics. The current date anchor was 2026-09-15; illustrative story dates preceded it.

- Ink & Paper: warm ivory/charcoal/lapis, editorial serif, small blue ink portrait,
  lead story beside recent writing, book-like collection compositions, panoramic
  gallery feature.
- Open Workshop: off-white/teal/coral, bold sans-serif, adult manga portrait,
  diagram-led feature, recent stories in a horizontal strip, flat colored
  collection modules, photography alongside text.
- Wide Horizons: ivory/charcoal/forest green, restrained serif, photographic
  portrait, lead photo and headline beside recent writing, horizontal collection
  entries, large night-sky photograph.

The renderer interpreted some instructions loosely: it added slogans, some covers
appear dimensional, and portrait crops vary. Assess visual direction and hierarchy
rather than accepting every generated detail. Preserve the original portrait as
the likeness reference during later refinement.
